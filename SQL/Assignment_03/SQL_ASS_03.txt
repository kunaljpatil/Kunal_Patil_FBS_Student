Q.4 Write a SQL statement to change the email column of employees table with 'not available' for those employees whose department_id is 80 :
UPDATE employees
SET email = 'not available'
WHERE department_id = 80;

Q.5 Write a SQL statement to change the email column of employees table with 'not available' for those employees who belongs to the 'Purchasing' department.
UPDATE employees
SET email = 'not available'
WHERE department_id IN (
    SELECT dept_id
    FROM department
    WHERE dept_name = 'PURCHASING'
);


Q6. Write a SQL statement to change the email and commission_pct column of employees table with 'not available' and 0.10 for all employees.

UPDATE employees
SET email = 'not available',
    commission_pct = 0.10;
